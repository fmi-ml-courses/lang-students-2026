# Лабораторные работы курса «Методы обработки естественного языка»

Магистратура, 2 курс, направление «Искусственный интеллект». 18 лабораторных работ. Для каждой есть две версии ноутбука Jupyter:

- `labXX_student.ipynb` — студенческий шаблон: теория, готовая инфраструктура, задания с заглушками `# TODO: ваш код` / `raise NotImplementedError`, проверочные `assert`, вопросы к защите;
- `labXX_teacher.ipynb` — версия преподавателя: те же ячейки с эталонными решениями, плюс блок «Для преподавателя» с ожидаемыми результатами, ответами на вопросы и замечаниями по проверке.

## Запуск

1. Откройте ноутбук в Google Colab (Файл → Загрузить блокнот) или в локальном Jupyter. Метаданные ноутбуков заданы для Colab с GPU.
2. Первая ячейка с кодом — общая настройка: импорты, `SEED`, `DEVICE`, папки `data/` и `artifacts/`, загрузка корпусов.
3. Флаг `FAST_DEV_RUN` в этой ячейке:
   - `True` (по умолчанию) — сокращённый прогон с уменьшенными моделями, данными и числом шагов; каждая работа выполняется на CPU за минуты (см. таблицу ниже);
   - `False` — полный эксперимент для GPU (Colab T4 или аналог): более крупные модели (Qwen2.5-0.5B/1.5B и др.), больше шагов, больше seed.
4. Зависимости: `torch`, `transformers`, `numpy`, `scipy`, `scikit-learn`, `pandas`, `matplotlib`; в отдельных работах — `sentencepiece`, `tokenizers`, `regex`, `triton` (ЛР 11, только GPU). В Colab всё, кроме `triton` на CPU-рантайме, установлено заранее.
5. Данные (Tiny Shakespeare, text8, AG News, бенчмарки сходства слов, модели Hugging Face) скачиваются автоматически при первом запуске.

## Принцип заданий

- Ключевые механизмы реализуются вручную: BPE, обратное распространение в RNN, attention, RoPE, AdamW, KV-cache, FlashAttention, GPTQ, LoRA, DPO, GRPO, SAE и т. д.; библиотеки `peft`, `trl`, TransformerLens не используются.
- После каждого задания стоит проверка (`assert` или сравнение с эталонной реализацией PyTorch/HF).
- Часть заданий — открытые (`# TODO` без `raise`): эксперимент, таблица или график, которые студент проектирует сам.
- В конце каждой работы есть 5 вопросов к защите; ответы и критерии — в версии преподавателя.

## Проверка эталонных решений

Версии преподавателя прогоняются целиком в режиме `FAST_DEV_RUN = True` на CPU (2 ядра, без GPU). Ожидаемые числа в блоках «Для преподавателя» для проверенных работ взяты из этих прогонов, для остальных даны как ориентировочные диапазоны. Ветки, требующие GPU (ядро Triton в ЛР 11 и режим `FAST_DEV_RUN = False`), в среде подготовки не запускались. Их нужно проверить в Colab перед занятием.
